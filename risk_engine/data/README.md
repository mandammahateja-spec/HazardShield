# HazardShield ML Training Data & Dictionary

## ⚠️ Synthetic Development Dataset Notice
The dataset generated by `generate_demo_data.py` (`demo_flood_hazard_data.csv`) is a **synthetically generated demonstration dataset**. It has been modeled using hydrological and geophysical mechanics (rainfall surge ratios, terrain slope pooling, and drainage saturation) specifically to develop, validate, and test the machine learning pipeline locally without requiring access to gated government telemetry APIs during development.

---

## 📋 Feature Dictionary

| Column | Data Type | Units | Range / Domain | Physical Description |
| :--- | :--- | :--- | :--- | :--- |
| `rainfall_72h_mm` | Float | mm | `2.0` - `420.0` | Cumulative 72-hour precipitation recorded by rain gauge or forecasted. |
| `rainfall_threshold_mm` | Float | mm | `55.0` - `110.0` | Maximum 72h precipitation tolerable by local terrain before runoff overwhelms base absorption. |
| `soil_saturation_ratio` | Float | Ratio | `0.10` - `0.98` | Antecedent soil moisture saturation (0 = dry soil, 1 = saturated pores). |
| `terrain_slope_degrees` | Float | Degrees | `0.5` - `25.0` | Average ground slope. Low slopes (< 4°) indicate flat alluvial floodplains prone to pooling. |
| `drainage_capacity_mm_day` | Float | mm/day | `25.0` - `160.0` | Stormwater drainage throughput per 24 hours. |
| `elevation_meters` | Float | Meters | `5.0` - `1200.0` | Mean elevation above mean sea level. |
| `river_distance_meters` | Float | Meters | `50.0` - `8000.0` | Distance to nearest major perennial river channel or primary drainage corridor. |
| `past_recurrence_count` | Integer | Count | `0` - `9` | Number of historical inundation events documented in district disaster archives. |
| `vulnerability_svi` | Float | Index | `15.0` - `95.0` | Social and infrastructure vulnerability index (0 to 100). |
| **`flood_hazard_occurred`** | **Integer** | **Binary Target** | `0` or `1` | **Target Variable**: 1 = Flood breach / dangerous inundation within 72h window; 0 = Habitation safe. |

---

## 🎯 Target Definition & Prediction Horizon
- **Target Variable**: `flood_hazard_occurred`
- **Definition**: The probability ($P \in [0.0, 1.0]$) that a given geographical sector will experience waterlogging/inundation exceeding safety thresholds within a **72-hour forecasting window**.
- **Prediction Horizon**: 72 hours from the observation timestamp.

---

## 🔄 Replacing with Real Historical Disaster Data
To replace the synthetic development dataset with real observational records (e.g., from the **Central Water Commission (CWC)**, **India Meteorological Department (IMD)**, or **Bhuvan/NRSC**):

1. Prepare your historical records CSV matching the column names specified above.
2. Save the CSV to `risk_engine/data/real_flood_hazard_data.csv`.
3. Retrain the model using:
   ```bash
   python risk_engine/ml/train.py --data risk_engine/data/real_flood_hazard_data.csv
   ```
4. Run evaluation:
   ```bash
   python risk_engine/ml/evaluate.py
   ```
5. The serialized pipeline in `risk_engine/ml/artifacts/flood_model.joblib` will automatically be reloaded by the FastAPI Risk Engine without requiring any code changes or API modifications.
